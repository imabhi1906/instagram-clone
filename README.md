| Task                      | Command                              |
| ------------------------- | ------------------------------------ |
| Create venv               | `uv venv`                            |
| Activate venv             | `source .venv/bin/activate`          |
| Create project            | `uv init .`                          |
| Run script (macos)        | `uv run ./main.`                     |
| Install from requirements | `uv sync`                            |
| Add package               | `uv add fastapi`                     |
| Remove package            | `uv remove fastapi`                  |
| Exit Virual Environment   | `deactivate`                         |
